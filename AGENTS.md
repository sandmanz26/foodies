# Notes for AI agents and developers

Read this first, then `docs/HISTORY.md` for why things are the way they are.

## What this is
A one-page brand site for **RIUH**, a fictional zero-proof (alcohol-free) coffee cocktail bar in Jakarta. Front end only; no backend, no CMS. The site copy is English; the project docs in `docs/` are in Indonesian, the owner's language.

## Commands
```bash
npm install
npm run dev        # local dev server
npm run build      # static site in dist/ (set SITE_URL first, see README)
npm run preview    # serve dist/
```
Media rebuild (only needed when source assets change; needs ffmpeg and Python 3 with numpy, Pillow, scipy):
```bash
HF_CDN_BASE=... npm run media:fetch   # download Higgsfield sources into assets-src/raw/
npm run media:retouch                 # bar logo removal, hero third-arm removal
npm run media:build                   # logo, photos, hero frames, drink clips, stir frames, icons, og.jpg
```

## Map
| Path | What |
| --- | --- |
| `index.html` | Page structure and all static copy; `%SITE_URL%` and `<!-- %JSON_LD% -->` are filled at build time |
| `vite.config.js` | Build config and the `riuh-site-meta` plugin (absolute URLs, JSON-LD, robots.txt, sitemap.xml) |
| `src/content.js` | **Single source of truth** for products, venue details, voucher, wall captions, house rules |
| `src/main.js` | Boot: wordmarks, story scene, marquee, section init |
| `src/sections/` | One module per interactive section: `hero`, `menu`, `stir`, `wall`, `voucher` (also house rules) |
| `src/lib/` | `dom` (helpers, responsive photos, sticky progress), `fx` (confetti, reveal), `growth` (tracking, WhatsApp, invite links), `state` (localStorage) |
| `src/brand/` | Wordmark paths (generated) and mascot/burst shapes |
| `src/*-manifest.json` | Generated by the media scripts; do not edit by hand |
| `public/media/` | Built media: photos (WebP), `hero/` frames, `drinks/` clips, `stir/` frames, `og.jpg` |
| `scripts/` | Media pipeline (see `package.json` scripts) |
| `assets-src/sources.json` | Every Higgsfield job used, with file names; raw files are gitignored |
| `docs/` | `HISTORY.md`, `BRAND.md`, `STRATEGY.md`, `GENERATION-LOG.md` |

## Conventions
- Edit copy and venue data in `src/content.js` or `index.html`, never inside section modules.
- No runtime dependencies. Plain ES modules, plain CSS. Keep it that way unless there is a strong reason.
- Colours are CSS custom properties on `:root` (`--tomat`, `--kunyit`, `--pandan`, `--langit`, `--jambu`, `--krim`, `--ink`); fonts are self-hosted via `@fontsource`.
- Scroll-driven sections (`hero`, `story`, `menu`) are tall containers with a `position: sticky` child; progress comes from `stickyProgress()` in `src/lib/dom.js`.
- Heavy media loads late: hero frames after `load`, drink clips and stir frames when their section approaches. Keep the first paint light.
- Every interaction has a keyboard path and respects `prefers-reduced-motion`.
- Drink names pair one Indonesian word with a cocktail family (Senja Tonic, Jambu Sour, Kelapa Cloud, Aren Old Fashioned, Telang Highball).

## Rules from the owner
- No AI slop: critique ("roast") every generation prompt before sending it and every result before using it.
- The Higgsfield budget the owner set is nearly spent (images 54/75, video 63.75/70). Ask before generating more.
- Front end only.

## Known gaps
Placeholders (venue details, WhatsApp number, voucher terms), AI-generated imagery including people, unvalidated vouchers, analytics not wired, no real-device testing yet. Full list: end of `docs/HISTORY.md`.
